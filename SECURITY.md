# Security policy

This repository is a maintained fork of Twig 1.34.0 for EC-CUBE 3.0.x shops, maintained by Umiushi Lab LLC (合同会社うみうしラボ). It keeps the version EC-CUBE 3.0.18 ships and backports published security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use **Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting).

- If the problem also affects the upstream project (https://github.com/twigphp/Twig), please report it there as well.
- When a new upstream advisory affects this version, the fix is backported and released as the next `-pN` version.

## Supported versions

Only the latest `-pN` tag on the `eccube3/1.34` branch.
